# Book Recommender System

This Streamlit application provides book recommendations using collaborative filtering techniques.

## Features

- **User Recommendations**: Get personalized book recommendations based on user reading history
- **Similar Books**: Find books similar to a book you enjoy
- **Popular Books**: Discover popular books based on ratings

## How to Use

1. Select the desired functionality from the sidebar navigation menu
2. For personalized recommendations, choose a user ID and the number of recommendations
3. For similar books, select a book from the dropdown and the number of similar books to find
4. For popular books, customize the number of books and randomization options

## Technology Stack

- Streamlit for the user interface
- Pandas and NumPy for data manipulation
- Scikit-learn for machine learning components
- Python's pickle module for model serialization

## Data Sources

The application uses a curated dataset of books with user ratings. The dataset includes book titles, authors, ratings, and cover images.
